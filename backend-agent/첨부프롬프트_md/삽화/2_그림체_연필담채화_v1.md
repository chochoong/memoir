# 삽화 그림체 — 연필담채화 v1 (pencil_wash)

책마다 고르는 삽화 그림체 셋 가운데 하나다. 화면 이름 「연필담채화」, 식별자 `pencil_wash`.
공통 양식(`2_그림양식_v3.md`)에 이 파일의 두 블록이 붙는다 (§1 은 공통 양식 바로 뒤, §2 는 맨 끝).

연필의 선과 명암이 그림의 뼈대이고, 그 위에 옅은 색을 엷게 더한 손그림이다. **흑백 연필화가 아니다** — 옅은 색이 꼭 들어간다(§2).
수채화 그림체의 문구(물이 번진 수채 질감 · 가장자리가 옅게 풀림)는 넣지 않는다 — 색이 넓게 번져 연필 선을 덮으면 수채화와 같아진다.
문구를 고치면 판 번호를 올리고 새 파일로 둔다 — 결과에 파일 해시가 남는다.

## 1. 그림체

```text
[그림체 — 연필담채화]
- 연필로 그린 스케치 위에 옅은 색을 엷게 더한 담채화. 손으로 그은 연필 선과 연필 명암이 또렷이 보인다.
- 색은 연필 선 위에 얇고 투명하게 군데군데 얹는다. 따뜻하고 차분한 옅은 색이고, 종이의 흰 바탕이 군데군데 남는다.
- 선이 형태와 명암을 잡고 색은 거든다. 스케치북에 손으로 그린 느낌이다.
```

## 2. 이 그림체에서 피할 것

```text
[이 그림체에서 피할 것]
- 색이 하나도 없는 흑백 그림으로 그리지 않는다. 옅은 색이 꼭 들어간다.
- 색을 화면 가득 진하게 칠하거나 넓게 번지게 해서 연필 선을 덮지 않는다.
- 두껍게 쌓은 물감이나 굵은 붓 자국으로 그리지 않는다.
```
