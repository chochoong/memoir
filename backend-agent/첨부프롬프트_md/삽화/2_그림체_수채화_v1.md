# 삽화 그림체 — 수채화 v1 (watercolor · 기본)

책마다 고르는 삽화 그림체 셋 가운데 하나다. 화면 이름 「수채화」, 식별자 `watercolor`. **고르지 않으면 이것이다** —
그림체를 고르기 전에 만든 책도 수채화로 본다. 공통 양식(`2_그림양식_v3.md`)에 이 파일의 두 블록이 붙는다
(§1 은 공통 양식 바로 뒤, §2 는 맨 끝 — `app/session/memoir_illust_theme.py` 의 `build_theme_prompt`).

내용은 앞선 그림 양식 v2 의 수채화 문구(따뜻한 회상 수채화 · 물이 번진 수채 질감과 종이결 · 따뜻하고 절제된 색 ·
가장자리가 옅게 풀림)를 그대로 옮긴 것이다. §2 는 다른 그림체(유화 · 연필담채화)의 표현이 섞이지 않게 더했다.
문구를 고치면 판 번호를 올리고 새 파일로 둔다 — 결과에 파일 해시가 남는다.

## 1. 그림체

```text
[그림체 — 수채화]
- 따뜻한 회상 수채화 일러스트. 물이 번진 부드러운 수채 질감과 종이결이 보인다.
- 따뜻하고 절제된 색. 채도를 낮춘다.
- 오래된 기억을 떠올리는 듯 가장자리가 옅게 풀린다.
```

## 2. 이 그림체에서 피할 것

```text
[이 그림체에서 피할 것]
- 두껍게 쌓은 물감이나 굵은 붓 자국으로 그리지 않는다.
- 진한 윤곽선으로 형태를 가두지 않는다.
```
