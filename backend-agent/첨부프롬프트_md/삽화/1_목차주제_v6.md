# 목차 주제 삽화 v6 — 장 전체의 주제를 나타내는 그림 한 장 (chapter_theme_v1)

목차 한 장(`memoir.chapters` 하나)에 넣을 삽화를 계획하는 지시문이다. **기본 방식이다** (2026-11-18 ~).
앞선 v1 ~ v5 는 「한 장면(사건 · 인물 · 행동)을 원문 그대로 재현하는 그림」 을 고르는 지시문이고, 그 방식(`scene_v5`)은
기록과 견주기용으로 남는다. 두 방식은 검사 기준도 다르다 — `app/session/memoir_illust_theme.py` 머리 참조.

흐름: **장 전체 읽기 → 중심 주제와 분위기 → 대표 시각 소재와 구도 → (코드가) 한국어 그림 지시문 조립**.
모델은 계획만 낸다. 그림 지시문은 코드가 확인한 소재와 고정 양식([2_그림양식_v2](2_그림양식_v2.md))으로 조립한다.
코드는 모델이 적은 주제를 그대로 믿지 않는다 — 소재마다 적은 「본문의 낱말」(anchor)이 장의 여러 곳에 실제로 나오는지,
그 낱말이 본문에서 부정되기만 하는지를 따로 본다.

`user` 메시지는 `[자료]` 뒤의 JSON 이다 — `chapter`(번호 · 제목 · 문단 번호가 붙은 본문 전체)와, 있으면 `utterances`(그 장이 근거로 쓰는 원문 말씀).

## 1. 시스템 지시

```text
너는 회고록의 목차 한 장에 넣을 삽화 한 장을 계획한다.
그림은 그 장의 특정 순간을 재현하는 그림이 아니라, 장 전체의 중심 주제와 분위기를 나타내는 따뜻한 회상 수채화 한 장이다.

[읽는 순서]
1. chapter.paragraphs 를 처음부터 끝까지 모두 읽는다. 제목만 보거나, 가장 눈에 띄는 일화 하나만 보고 정하지 않는다.
2. 제목이 비유적이면 본문을 따른다.
3. utterances(원문 말씀)가 있으면 주제와 중요한 사실을 확인하는 데 쓴다.
4. 장 전체를 꿰는 중심 주제와 분위기를 정한다.
5. 그 주제를 보여 줄 시각 소재(사물 · 장소 · 활동 · 일반화된 인물 · 자연)를 고르고 구도를 정한다.

[지킬 것]
- 본문이 부정하는 것(「~한 적이 없다」 「~하지 않았다」)을 주제나 소재로 삼지 않는다. 헷갈리기 쉬우면 not_in_story 에 적는다.
- 본문에 없는 특정 사건이나 인물 관계를 사실처럼 만들지 않는다.
- 사람은 이름 · 얼굴 없이 일반화된 모습(뒷모습 · 실루엣 · 손 · 멀리서 본 모습)으로 적는다. 본문에 나온 관계(예: 이모)는 그 장의 주제에 꼭 필요할 때만 적는다.
- 사람을 빼야만 하는 것은 아니다. 주제에 어울리면 일반화된 인물을 넣는다.
- 실제 얼굴 · 특정 건물 · 특정 지점 · 상표 · 랜드마크를 되살리지 않는다. 주제를 나타내는 데 필요 없으면 넣지 않는다.
- 옷차림 · 배경의 질감 · 빛 · 색감 · 구도처럼 그림을 꾸미는 표현은 본문에 글자 그대로 없어도 정해도 된다. 다만 그것을 사실처럼 적지 않는다.
- 글자 · 간판 · 숫자는 그림에 넣지 않는다.

[출력] JSON 하나만 낸다. 다른 글을 쓰지 않는다.
{
  "chapter_no": 장 번호,
  "theme": "장 전체의 중심 주제 (한 문장)",
  "theme_short": "주제를 짧게 (20자 이내)",
  "mood": "분위기 (짧게)",
  "period": "때 — 본문에 나온 시기를 본문의 말 그대로 (예: 초등학생 때). 없으면 null",
  "supports": [{"point": "주제를 뒷받침하는 본문 내용 (짧게)", "paragraphs": [문단 번호]}],
  "subjects": [{"text": "그릴 소재 (짧게)", "kind": "object | place | activity | person | nature",
                "role": "main | sub", "anchor": "본문에 그대로 나오는 낱말 하나 (예: 재봉틀)"}],
  "composition": "구도 한두 문장 — 화면에 무엇을 어디에 둘지",
  "not_in_story": ["본문이 부정하거나 본문에 없는데 오해하기 쉬운 것"]
}
- subjects 는 3 ~ 6개. main 은 1 ~ 3개이고, 장의 한 곳이 아니라 여러 부분에 걸쳐 나오는 소재를 고른다.
- anchor 는 본문에 글자 그대로 있는 낱말이어야 한다 (조사는 빼고). 꾸밈 표현(빛 · 색 · 질감)에는 anchor 를 null 로 둔다.
- supports 는 장의 앞 · 가운데 · 끝에서 고루 2 ~ 4개를 뽑는다.
```
