# 삽화 그림 양식 v3 — 목차 주제 삽화의 공통 양식 (그림체와 상관없는 부분)

목차 주제 삽화(`chapter_theme_v2`)의 그림 지시문에 **글자 그대로** 붙는 고정 문구다. 그림 재료 · 붓질 · 색감(그림체)은 여기에 없다 —
책마다 고른 그림체 파일 하나(`2_그림체_수채화_v1.md` · `2_그림체_연필담채화_v1.md` · `2_그림체_유화_v1.md`)가 따로 붙는다.
`app/session/memoir_illust_theme.py` 의 `build_theme_prompt` 가 각 절의 첫 ``` 블록을 읽어
「공통 양식 → 그림체 → 이 장의 주제 · 그릴 것 → 인물 표현 → 넣지 않는 것 → 이 그림체에서 피할 것」 순서로 잇는다.

v2(`2_그림양식_v2.md`)와 다른 점 — v2 는 양식 안에 수채화(물 번짐 · 종이결 · 가장자리가 옅게 풀림 · 절제된 색)를 고정했다.
v3 은 그것을 `2_그림체_수채화_v1.md` 로 옮기고, 그림체와 상관없는 것만 남겼다. 인물 표현 · 넣지 않는 것은 v2 와 글자까지 같다.
v2 는 그 판(2026-11-18 ~ 11-24)으로 만든 기록의 근거로 남는다. 문구를 고치면 판 번호를 올리고 새 파일로 둔다 — 결과에 파일 해시가 남는다.

## 1. 공통 양식

```text
[그림 양식]
회고록 본문에 들어갈 삽화 한 장을 그린다.
- 그림 재료와 붓질은 아래 [그림체] 하나만 따른다. 다른 곳에 재료 이름이 보여도 [그림체] 를 따른다.
- 차분하고 여백이 있는 구도. 화려한 효과를 쓰지 않는다.
- 사진처럼 보이지 않는 손그림이다.
- 이 장의 주제와 분위기를 한 장에 담는다. 특정 한 순간을 사실 그대로 재현한 그림이 아니다.
- 시대와 장소는 아래 「이 장의 주제」 에 적힌 때보다 더 구체적으로 정하지 않는다.
```

## 2. 인물 표현

```text
[인물 표현]
- 사람을 넣을 때는 얼굴을 자세히 그리지 않는다. 뒷모습, 멀리서 본 작은 모습, 실루엣, 손이나 몸짓으로 나타낸다.
- 실제 인물의 생김새를 되살린 그림이 아니다. 일반화된 모습으로 그린다.
- 「그릴 것」 에 없는 특정 인물이나 인물 사이의 관계를 새로 만들지 않는다.
```

## 3. 넣지 않는 것

```text
[넣지 않는 것]
- 본문에 없는 특정 사건이나 인물 관계를 사실처럼 그려 넣지 않는다. 화면을 채우는 배경은 일반적으로만 그린다.
- 글자 · 간판 · 상표 · 로고 · 날짜 · 숫자를 그리지 않는다.
- 알아볼 수 있는 특정 건물 · 지명 · 랜드마크 · 역사적 사건을 그리지 않는다.
- 눈물 · 통곡 · 극적인 빛처럼 감정을 과장하는 표현을 쓰지 않는다.
- 사진 · 실사 · 초상화 같은 표현으로 그리지 않는다.
```
