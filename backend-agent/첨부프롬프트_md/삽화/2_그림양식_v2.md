# 삽화 그림 양식 v2 — 목차 주제를 나타내는 따뜻한 회상 수채화 (watercolor-recall-v2)

목차 주제 삽화(`chapter_theme_v1`)의 그림 지시문에 **글자 그대로** 붙는 고정 문구다.
`app/session/memoir_illust_theme.py` 의 `build_theme_prompt` 가 각 절의 첫 ``` 블록을 읽어
「양식 → 이 장의 주제 · 그릴 것 → 인물 표현 → 넣지 않는 것」 순서로 잇는다.

v1(`2_그림양식_v1.md`)과 다른 점 — v1 은 한 장면을 원문 그대로 재현하는 그림용이라 「한국의 옛 생활 모습」 으로 고정하고
인물 칸에 없는 사람을 금지했다. v2 는 장의 주제를 나타내는 그림이라, 시대는 그 장의 「때」 를 따르고 일반화된 인물 표현을 허용한다.
v1 은 장면 방식(`scene_v5`)이 그대로 쓴다. 문구를 고치면 판 번호를 올리고 새 파일로 둔다 — 결과에 파일 해시가 남는다.

## 1. 양식

```text
[그림 양식]
회고록 본문에 들어갈 삽화 한 장을 그린다.
- 따뜻한 회상 수채화 일러스트. 물이 번진 부드러운 수채 질감과 종이결이 보인다.
- 따뜻하고 절제된 색. 채도를 낮추고 화려한 효과를 쓰지 않는다.
- 차분하고 여백이 있는 구도. 오래된 기억을 떠올리는 듯 가장자리가 옅게 풀린다.
- 사진처럼 보이지 않는 손그림이다.
- 이 장의 주제와 분위기를 한 장에 담는다. 특정 한 순간을 사실 그대로 재현한 그림이 아니다.
- 시대와 장소는 아래 「이 장의 주제」 에 적힌 때보다 더 구체적으로 정하지 않는다.
```

## 2. 인물 표현

```text
[인물 표현]
- 사람을 넣을 때는 얼굴을 자세히 그리지 않는다. 뒷모습, 멀리서 본 작은 모습, 실루엣, 손이나 몸짓으로 나타낸다.
- 실제 인물의 생김새를 되살린 그림이 아니다. 일반화된 모습으로 그린다.
- 「그릴 것」 에 없는 특정 인물이나 인물 사이의 관계를 새로 만들지 않는다.
```

## 3. 넣지 않는 것

```text
[넣지 않는 것]
- 본문에 없는 특정 사건이나 인물 관계를 사실처럼 그려 넣지 않는다. 화면을 채우는 배경은 일반적으로만 그린다.
- 글자 · 간판 · 상표 · 로고 · 날짜 · 숫자를 그리지 않는다.
- 알아볼 수 있는 특정 건물 · 지명 · 랜드마크 · 역사적 사건을 그리지 않는다.
- 눈물 · 통곡 · 극적인 빛처럼 감정을 과장하는 표현을 쓰지 않는다.
- 사진 · 실사 · 초상화 같은 표현으로 그리지 않는다.
```
