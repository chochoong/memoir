# 삽화 그림 양식 v1 — 따뜻한 회상 수채화 (watercolor-recall-v1)

자서전 삽화의 그림 지시문에 **글자 그대로** 붙는 고정 문구다. `app/session/memoir_illust.py` 의
`build_prompt` 가 각 절의 첫 ``` 블록을 읽어 「양식 → 그릴 장면(확인된 요소) → 인물 표현 → 넣지 않는 것」
순서로 잇는다. 장면마다 바뀌는 것은 「그릴 장면」 뿐이다.

첫 구현의 양식은 이 하나다. 문구를 고치면 판 번호를 올리고 새 파일로 둔다 — 결과에 파일 해시가 남는다.
어느 이미지 모델에 맞춘 문구가 아니다. 모델이 정해지면 그 모델의 지시문 형식에 맞게 옮겨야 한다.

## 1. 양식

```text
[그림 양식]
회고록 본문에 들어갈 삽화 한 장을 그린다.
- 따뜻한 회상 수채화 일러스트. 물이 번진 부드러운 수채 질감과 종이결이 보인다.
- 따뜻하고 절제된 색. 채도를 낮추고 화려한 효과를 쓰지 않는다.
- 차분하고 여백이 있는 구도. 오래된 기억을 떠올리는 듯 가장자리가 옅게 풀린다.
- 사진처럼 보이지 않는 손그림이다.
- 한국의 옛 생활 모습으로 그리되, 아래 「그릴 장면」 에 적힌 때와 장소보다 더 구체적으로 정하지 않는다.
```

## 2. 인물 표현

```text
[인물 표현]
- 사람의 얼굴을 자세히 그리지 않는다. 뒷모습, 멀리서 본 작은 모습, 실루엣, 손이나 몸짓으로 나타낸다.
- 실제 인물의 생김새를 되살린 그림이 아니다. 나이 · 체격 · 옷차림은 「그릴 장면」 에 적힌 만큼만 따른다.
- 「그릴 장면」 의 인물 칸에 없는 사람을 그려 넣지 않는다.
```

## 3. 넣지 않는 것

```text
[넣지 않는 것]
- 「그릴 장면」 에 없는 사건 · 행동 · 주요 사물을 더하지 않는다. 화면을 채우는 배경은 눈에 띄지 않게 일반적으로만 그린다.
- 글자 · 간판 · 상표 · 날짜 · 숫자를 그리지 않는다.
- 알아볼 수 있는 특정 건물 · 지명 · 역사적 사건을 그리지 않는다.
- 눈물 · 통곡 · 극적인 빛처럼 감정을 과장하는 표현을 쓰지 않는다.
- 사진 · 실사 · 초상화 같은 표현으로 그리지 않는다.
```
