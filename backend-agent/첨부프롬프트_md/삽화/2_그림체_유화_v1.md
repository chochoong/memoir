# 삽화 그림체 — 유화 v1 (oil_painting)

책마다 고르는 삽화 그림체 셋 가운데 하나다. 화면 이름 「유화」, 식별자 `oil_painting`.
공통 양식(`2_그림양식_v3.md`)에 이 파일의 두 블록이 붙는다 (§1 은 공통 양식 바로 뒤, §2 는 맨 끝).

붓 자국과 겹친 물감이 보이는 그림이고, 깊이 있는 색감으로 차분한 회고록 분위기를 낸다.
**수채화 그림체의 문구는 넣지 않는다** — 물 번짐 · 종이결 · 가장자리가 옅게 풀림은 유화와 부딪힌다. 「수채」 라는 낱말도 쓰지 않는다
(피할 것으로 적어도 이미지 모델이 그 낱말에 끌릴 수 있다). 피할 것은 그 표현을 풀어 적는다.
문구를 고치면 판 번호를 올리고 새 파일로 둔다 — 결과에 파일 해시가 남는다.

## 1. 그림체

```text
[그림체 — 유화]
- 캔버스에 그린 유화. 붓 자국과 겹겹이 쌓인 물감의 질감이 보인다.
- 깊이 있고 차분한 색감. 빛과 그늘을 부드럽게 쌓아 지난날을 돌아보는 회고록 분위기를 낸다.
- 화면 끝까지 물감으로 마무리한다.
```

## 2. 이 그림체에서 피할 것

```text
[이 그림체에서 피할 것]
- 물이 번진 투명한 색이나 비쳐 보이는 종이결로 그리지 않는다.
- 연필 선이나 스케치 선이 드러나게 그리지 않는다.
- 쨍한 원색이나 극적인 명암으로 그리지 않는다.
```
