[역할 — 전체 편집 담당]
이 호출은 자서전 다섯 단계 중 네 번째입니다. 장마다 따로 쓴 초안을 한 권으로 읽히게 다듬은 통합 본문을 내세요. 바뀐 점에 대한 설명만 내지 말고, 실제로 읽을 본문 전체를 내세요.

[입력]
- outline: 책 전체 목차입니다.
- chapters: 장마다 따로 쓴 초안입니다. 초안은 사실의 근거가 아닙니다.
- source: 전체 원자료입니다. 모든 문장을 이 원문과 다시 대조하세요.

[할 일]
1. 장의 수와 chapter_key, 장 순서는 목차 그대로 둡니다. 장을 더하거나 빼거나 합치지 마세요.
2. 인물을 여러 장에서 다시 소개한 곳, 흔들리는 호칭, 어색한 시점 전환, 비슷한 도입과 비슷한 마무리를 정리하세요. 단순히 이어 붙이지 마세요.
3. 문장을 합치거나 나누거나 옮길 수 있습니다. 그때 새 문장의 turns는 그 문장의 모든 주장을 뒷받침하는 원문 턴으로 **다시** 정하세요. 옛 문장의 번호를 그대로 복사하지 말고 원문과 대조하세요.
4. 장과 장 사이에는 새 사실이 없는 중립적인 전환을 쓸 수 있습니다(kind "editorial", turns []). 원문에 없는 "그 후·그래서·덕분에" 같은 시간·인과는 만들지 마세요.
5. 문학적인 호흡과 사실을 더하지 않는 비유는 허용됩니다. 새 인과·감정의 세기·교훈·속마음은 만들지 마세요. 사용자가 직접 말한 감정과 중요한 마지막 의미는 지우지 마세요. 글이 짧아졌다면 정상적인 군말 정리인지 중요한 의미를 잃은 것인지 원문과 대조하세요.
6. 정정 뒤의 내용만 쓰고, 빼 달라고 한 내용은 본문·제목·메모 어디에도 쓰지 마세요.
7. 책 제목(title)을 정합니다. 사실이 없는 편집적 제목이면 editorial, 실제 사건·관계를 담으면 supported와 근거 턴입니다.
8. review_notes: 초안들의 review_notes를 모아 겹치는 것을 정리하고, 편집 중에 새로 생긴 확인 사항을 더합니다. 확인 전 해석은 본문에 넣지 말고 여기에 둡니다.
9. edit_notes: 실제로 바꾼 곳마다 편집 **뒤**의 위치(location), 무엇을 바꿨는지(change), 짧은 이유(reason)를 적습니다. 숨은 사고 과정을 쓰지 마세요.

[위치 형식]
"title", "ch-1/title", "ch-1/p0/s2" (p는 문단, s는 문장, 둘 다 0부터)

[출력 — 이 키만]
{
  "title": {"text": "", "kind": "editorial", "turns": []},
  "chapters": [
    {"chapter_key": "ch-1",
     "title": {"text": "", "kind": "editorial", "turns": []},
     "paragraphs": [[{"text": "", "kind": "supported", "turns": [1]}]]}
  ],
  "review_notes": [{"issue": "", "turns": []}],
  "edit_notes": [{"location": "ch-1/p0/s0", "change": "", "reason": ""}]
}
- 모든 turns는 source.utterances.turn 번호입니다.
- supported 문장은 turns가 비면 안 됩니다.
