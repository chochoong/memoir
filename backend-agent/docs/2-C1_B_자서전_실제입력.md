# 2-C1/B — 자서전 검증용 실제 조립 자료 (P2-SV-06)

작성 최충 · 받는 사람 김대원 · 안다애
기준 코드 `feature/theme-interview` · 합성 세트 `eval/memoir_seed_B.json` (memoir-seed-v1.1)

## 1. 어떻게 만들었나

손으로 쓴 예시가 아니다. 아래 두 명령의 출력이다.

```
python tools/seed_sessions.py --input eval/memoir_seed_B.json --manifest eval/memoir_seed_B.ids.json
python tools/memoir_input.py --manifest eval/memoir_seed_B.ids.json --aliases s-r1,s-r2,s-r3 --out eval/memoir_input_B3.json
```

- 첫 줄은 합성 회차를 이 PC 의 DB(`localhost:5432/memoir`)에 넣는다. 엽서는 굽지 않았다.
- 둘째 줄은 DB 에서 `store.load_session` 으로 지금 저장된 회차를 읽고, 서버의
  `/api/memoirs/preview` 와 **같은 함수**(`memoir.check_selection` → `memoir.merge`,
  회차 안은 `postcard.material`)로 합친다. 모델은 부르지 않는다.
- 아래 JSON 은 그 파일의 `input_alias` · `turn_map_alias` 를 그대로 옮긴 것이다. 실제 UUID 를
  alias 로 바꾼 것 말고는 손대지 않았다. UUID 판은 같은 파일의 `input` · `turn_map` 이다
  (`eval/*` 는 DB 마다 달라 저장소에 올리지 않는다).
- 실행 도구를 새로 만들지 않았다. 2차 B 의 실행 도구는 김대원 님 몫이다.

## 2. 화자 · 회차 · 기록 순서

화자 `dev-user` (개발용 사용자값 — 인증이 아니다) · 넣은 시각 2026-10-20T06:16:24+00:00

| alias | 기록 순서 | session_id | 제목 |
|---|---|---|---|
| s-r1 | 1 | `31acffd4-3c08-44df-a32c-f742a5c3dd1d` | [B] 딸 입학 원진술 |
| s-r2 | 2 | `08b0b2c5-7ce0-4834-8177-738836959102` | [B] 꽃집과 제외 요청 |
| s-r3 | 3 | `6fcb88d8-e170-4d71-ae0c-a273f1575d91` | [B] 입학 연도 정정 |

- 기록 순서는 회차를 연 시각(`created_at`)으로 merge 가 세운다. seed 의 `recorded_order` 대로
  넣은 시각에 1분씩 더해 넣었고, 결과의 `recorded_order` 도 1 · 2 · 3 이다.
- **다른 사람 회차는 섞이지 않는다.** 같은 회차를 화자 `other-user` 로 읽게 하면
  「이 DB 에 없는 회차다」로 멈추고 파일을 쓰지 않는다 (확인함). 서버 라우트도 같은 조건으로 404 다.
- **3~5개 제한은 그대로다.** 2개로 돌리면 `BadSelection: 회차 2개 — 3~5개여야 한다` 로 멈춘다 (확인함).

## 3. 수정 · 제외의 유효 범위

**원문 수정 기능은 아직 없다** (P2-SV-02~05 미착수). 그래서 수정 전과 수정 후의 원문이 같다 —
DB 에 저장된 말씀이 그대로 유효 원문이다. 이 세트의 정정과 제외는 **말씀 안에서** 한 것이다.

| 무엇 | 어디 (전역 턴) | merge 가 한 일 | 반영은 누가 |
|---|---|---|---|
| 입학 연도 정정 1998 → 1996 | 원진술 s-r1 1턴(1) · 정정 s-r3 1턴(6) | 두 말씀 모두 싣는다. `confirmed_facts` 에 「딸 입학 1998년」과 「딸 입학 1996년」이 **둘 다** 있다 | 모델 (자서전.md 지침) |
| 돈 빌린 이야기 · 금액 제외 | 원진술 s-r2 2턴(4) · 제외 요청 s-r2 3턴(5) | 두 말씀 모두 싣는다. 「누나에게 삼백만 원 빌림」이 `confirmed_facts` 에 **남아 있다** | 모델 (자서전.md 지침) |
| 꽃집 · 첫 손님은 남김 | s-r2 1턴(3) | 싣는다 | — |

- merge 는 회차를 넘어 사실을 지우거나 고치지 않는다. 같은 글자의 사실만 한 번으로 줄인다.
  회차 안에서 `facts_retracted` 로 물린 것만 빠지는데, 이 세트에는 그런 판단이 없다.
- 그래서 지금 B 의 정정 · 제외는 **입력에서 걸러지지 않고 모델이 지켜야 한다.** 모델 결과에
  1998년이나 삼백만 원이 나오면 입력이 아니라 글쓰기 쪽 문제로 본다. 입력 단계에서 거를지는
  P2-SV-02~05(부분 수정)와 2-C1 합의 뒤에 정한다.

## 5. 전역 턴 대응표 (`turn_map_alias`)

모델의 `sources[].turns` 는 왼쪽 `global_turn` 이다. 회차 안 턴으로 되돌릴 때 이 표를 쓴다.

```

{"global_turn": 2, "session_id": "s-r1", "turn": 2}
```

## 6. 실행 기록 (2-R1)

| 구분 | 내용 | 판정 |
|---|---|---|
| 도구 | seed_sessions(회차 3 · 엽서 0) → memoir_input. 회차 3 · 말씀 7턴 · 사실 6개 | 조립 완료 |

| 앱 · 화면 | 엽서가 없어 화면에서는 이 세 회차를 고를 수 없다 (`--bake-postcards` 필요) | 실행 안 함 |
