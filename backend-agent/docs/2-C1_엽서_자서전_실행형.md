closed_fn 이 걸려 있을 때만 돌기 때문에 자리는 남기고 굽기만 뺐다.

## 2. 키 차이 — 요청 / 모델 / 화면

**엽서** `POST /api/sessions/{id}/postcard`

| | 키 |
|---|---|
| 요청 본문 | 없음 (`X-User-Id`) |
| 모델 입력 | `shared_state{confirmed_facts, facts_found, photo_analyses?}` · `utterances[{turn, asked, elder}]` |
| 모델 출력 (8) | `status` `title` `body` `sources` `to_confirm` `missing_context` `coverage_notes` `caption` |
| 화면 응답 | `url` `title` `text`(= 모델 `body`) `caption` `width` `height` `bytes` — 바뀌지 않음 |

| 모델 status | HTTP | 저장 |
|---|---|---|
| `ready` | 200 | 글 · JPEG 저장 |
| `insufficient_material` | 409 「엽서에 담을 만큼 확실한 말씀이 없습니다」 | 안 함 |
| `needs_confirmation` · `needs_context` | 503 「엽서 글을 만들지 못했습니다」 | 안 함 (로그에 상태 · 사유) |
| 그 밖 | 503 | 안 함 |

키가 8개와 다르면 로그만 남긴다. 굽는 데 쓰는 것은 `title` `body` `caption` `sources` 다.
출처 없는 문장은 아직 경고만 한다 — P2-SV-05 에서 정한다.

**자서전** `POST /api/memoirs/preview`

| | 키 |
|---|---|
| 요청 본문 | `session_ids` (3~5) |
| 모델 입력 | `shared_state{confirmed_facts, facts_found}` · `sessions[{session_id, recorded_order}]` · `utterances[{turn, session_id, asked, elder}]` |
| 모델 출력 (7) | `status` `title` `body` `sources` `to_confirm` `missing_context` `coverage_notes` — 정확히 7개가 아니면 502 |
| 화면 응답 (5) | `status` `title` `body` `sources` `to_confirm` — 바뀌지 않음. 나머지 둘은 로그에만 |

| 모델 status | HTTP |
|---|---|
| `ready` | 200 |
| `insufficient_material` | 200 (실패 아님) |
| `needs_confirmation` · `needs_context` | **503 (새로 생김)** 「지금은 자서전을 만들 수 없어요. 엽서 선택 화면으로 돌아가 주세요.」 |
| 구조 어긋남 · 호출 실패 / 시간 초과 | 502 / 504 (그대로) |

실제 모델 결과 — 엽서는 8키 · `ready` · 2문장 · 출처가 문장마다 실제 턴. 자서전은 7키 ·
`ready` · 6문장 · 출처가 문장마다 실제 전역 턴. **구조 판정이다.** 문장의 뜻이 원문과
맞는지는 김대원 · 안다애 님 검수 몫이다. 자서전은 회차당 2문장이라 기본 3~8문장보다
적다(자료가 적은 회차의 예외 허용 범위인지 확인 필요). 앱 · 화면 경로는 실행하지 않았다.
