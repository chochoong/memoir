## 2. 키 차이 — 요청 / 모델 / 화면

**엽서** `POST /api/sessions/{id}/postcard`

| | 키 |
|---|---|
| 요청 본문 | 없음 (`X-User-Id`) |
| 모델 입력 | `shared_state{confirmed_facts, facts_found, photo_analyses?}` · `utterances[{turn, asked, elder}]` |
| 모델 출력 (8) | `status` `title` `body` `sources` `to_confirm` `missing_context` `coverage_notes` `caption` |
| 화면 응답 | `url` `title` `text`(= 모델 `body`) `caption` `width` `height` `bytes` — 바뀌지 않음 |

| 모델 status | HTTP | 저장 |
|---|---|---|
| `ready` | 200 | 글 · JPEG 저장 |
| `insufficient_material` (본문이 빈 경우 포함) | 409 `code: insufficient_material` | 안 함 |
| `needs_confirmation` · `needs_context` | 503 「엽서 글을 만들지 못했습니다」 | 안 함 (로그에 상태 · 사유) |
| 그 밖 | 503 | 안 함 |

409 는 원인이 넷이라 본문에 `code` 를 함께 싣는다 (`{"detail": 안내, "code": ...}`).
`detail` 은 그대로라 `detail` 만 읽는 화면도 바뀌지 않는다. 409 말고는 지금처럼 `detail` 뿐이다.

| code | 원인 | detail |
|---|---|---|
| `not_closed` | 회차가 아직 안 끝났다 | 회차를 마친 뒤에 엽서를 만들 수 있습니다 |
| `no_answers` | 남은 말씀이 없다 | 남은 말씀이 없어 엽서를 만들 수 없습니다 |
| `busy` | 같은 회차를 이미 굽는 중 | 엽서를 만드는 중입니다. 잠시 기다려 주세요 |
| `insufficient_material` | 담을 만큼 확실한 말씀이 없다 (자서전과 같은 이름) | 엽서에 담을 만큼 확실한 말씀이 없습니다 |

화면 응답 예시 (200). 글은 2-R1 실제 모델 결과(합성 seed A, s-a) 그대로다. 그 실행은
굽지 않았으므로 `url` 의 꼬리 · `bytes` 는 모양만 보이는 값이다.

```json
{
  "url": "/api/sessions/3f0c…/postcard?v=9a1b2c3d",
  "title": "첫 월급과 목도리",
  "text": "1979년에 광주 인쇄소에서 첫 월급을 받았어요.\n그 돈으로 어머니께 빨간 목도리를 사 드려 참 뿌듯했어요.",
  "caption": "",
  "width": 1500,
  "height": 1000,
  "bytes": 214000
}
```

409 예시: `{"detail": "엽서에 담을 만큼 확실한 말씀이 없습니다", "code": "insufficient_material"}`

키가 8개와 다르면 로그만 남긴다. 굽는 데 쓰는 것은 `title` `body` `caption` `sources` 다.
출처 없는 문장은 아직 경고만 한다 — P2-SV-05 에서 정한다.

**자서전** `POST /api/memoirs/preview`

| | 키 |
|---|---|
| 요청 본문 | `session_ids` (3~5) |
| 모델 입력 | `shared_state{confirmed_facts, facts_found}` · `sessions[{session_id, recorded_order}]` · `utterances[{turn, session_id, asked, elder}]` |
| 모델 출력 (7) | `status` `title` `body` `sources` `to_confirm` `missing_context` `coverage_notes` — 정확히 7개가 아니면 502 |
| 화면 응답 (5) | `status` `title` `body` `sources` `to_confirm` — 바뀌지 않음. 나머지 둘은 로그에만 |

| 모델 status | HTTP |
|---|---|
| `ready` | 200 |
| `insufficient_material` | 200 (실패 아님) |
| `needs_confirmation` · `needs_context` | **503 (새로 생김)** 「지금은 자서전을 만들 수 없어요. 엽서 선택 화면으로 돌아가 주세요.」 |
| 구조 어긋남 · 호출 실패 / 시간 초과 | 502 / 504 (그대로) |

자서전 API 에서 503 은 `needs_*` 일 때만 나간다. 나머지 실패는 400 선택 오류 · 404 엽서 없는
회차 · 422 자료를 못 읽음 · 502 · 504 이고, 실패 본문은 모두 `{"detail": 안내}` 뿐이다.

화면 응답 예시 (200). 2-R1 실제 모델 결과(합성 seed A, s-a · s-b · s-c) 그대로다.
모델은 7키로 답했고 `missing_context` · `coverage_notes` 는 둘 다 빈 목록이라 로그에만 남았다.

```json
{
  "status": "ready",
  "title": "광주 인쇄소 첫 월급과 가족과의 기억",
  "body": "1979년에 광주 인쇄소에서 첫 월급을 받았어요.\n그 돈으로 어머니께 빨간 목도리를 사 드렸어요.\n1985년쯤 동생과 기차를 타고 전주로 놀러 갔어요.\n기차를 처음 탄 건 동생이에요.\n1996년에 딸이 초등학교에 입학해서 제가 데려다줬어요.\n노란 가방을 메고 교실에 들어가는 딸을 보았어요.",
  "sources": [
    {"sentence": 0, "turns": [1]}, {"sentence": 1, "turns": [2]},
    {"sentence": 2, "turns": [3]}, {"sentence": 3, "turns": [4]},
    {"sentence": 4, "turns": [5]}, {"sentence": 5, "turns": [6]}
  ],
  "to_confirm": []
}
```

자료 부족 예시 (200): `{"status": "insufficient_material", "title": "", "body": "", "sources": [], "to_confirm": []}`

### 자서전 시험 자료 (강승우 Q6)

자서전은 엽서가 있는 회차만 받는다(`memoir.collect`). 이제 회차가 끝나도 엽서를 굽지 않으므로
「엽서 만들기」 버튼(FE-07 · 13)이 붙기 전에는 새 회차를 고를 수 없다. **그때까지는 시드
자료로 시험한다** — `tools/seed_sessions.py --bake-postcards` 가 `POST /postcard` 를 직접
불러 엽서를 굽는다. 엽서 없는 회차를 받게 바꾸지 않는다 — 「수정 반영 · 무수정 확인 뒤에만
생성」을 자서전이 건너뛰게 된다.

실제 모델 결과 — 엽서는 8키 · `ready` · 2문장 · 출처가 문장마다 실제 턴. 자서전은 7키 ·
`ready` · 6문장 · 출처가 문장마다 실제 전역 턴. **구조 판정이다.** 문장의 뜻이 원문과
맞는지는 김대원 · 안다애 님 검수 몫이다. 자서전은 회차당 2문장이라 기본 3~8문장보다
적다(자료가 적은 회차의 예외 허용 범위인지 확인 필요). 앱 · 화면 경로는 실행하지 않았다.
