# 6-C1 — 기록 목록 정렬 현황 · 초안 (P6-SV-01)

작성 최충 · 받는 사람 김대원 (DW-12) · 강승우 (FE-11) · 안다애 (P6-QA-02) · 확인 태헌
기준 서버 `feature/theme-interview` `ad797ec` 뒤 · 2026-10-22

**현행과 결정할 것을 적었다. 연대기 정렬은 아직 없다** — 사건 시점을 저장하는 칸이 없다.

## 1. 세 가지 「때」를 섞지 않는다

| 이름 | 뜻 | 지금 어디에 |
|---|---|---|
| 작성 시각 | 회차를 연 때 | `session.created_at` (UTC, 화면이 한국 시각으로 표시). 엽서를 다시 구워도 안 바뀐다 |
| 사건 시점 | 어르신이 말한 경험의 때 | **없다** (§2) |
| 서술 순서 | 자서전에서 놓는 차례 | 자서전 응답 안에만 · 저장 안 함 (7-C1) |

## 2. 지금 목록 · 지금 있는 시점 자료

`GET /api/sessions?limit=&has_postcard=`

| 항목 | 지금 |
|---|---|
| 정렬 | 작성 시각 최신순 하나 (`ORDER BY created_at DESC`) |
| 범위 | 로그인한 계정의 회차만 · `has_postcard=1` 이면 엽서 있는 회차만 |
| 크기 | `limit` 1~100 (기본 20). **다음 쪽 · 더 보기가 없다** — 100개 넘는 기록은 목록으로 끝까지 볼 수 없다 |
| 칸 | `session_id · title · has_postcard · postcard_title · created_at` 외 (`엽서목록제목_C1_R1.md` C1) |
| 단위 | 회차 하나 = 한 줄 |

사건 시점처럼 보이지만 **쓰면 안 되는 것**:

| 자료 | 무엇인가 | 왜 안 되나 |
|---|---|---|
| 인터뷰 판단의 `information_status.when` | `missing` / 확인됨 — 「때를 물어봤나」 표시 | 연도 값이 아니다 |
| `confirmed_facts` | 「16년 7월에 말랑이를 만났다」 같은 자유 문장 | 구조가 없다 — 여기서 연도를 뽑는 것이 대원 님 추출 몫이다 |
| `photo.exif_taken_at` | 사진을 찍거나 스캔한 때 | 기억의 연도가 아니다 (`photo.py` 머리) · 지시서도 사진으로 연도를 계산하지 말라고 한다 |
| `created_at` | 작성 시각 | 사건 시점이 아니다 |

## 3. 시점 칸 — 합의할 것 (대원 님 추출 형식을 받아 고친다)

연대기 프롬프트의 정밀도 (`exact · approximate · range · relative · unknown`) 를 의미 기준으로 쓴다.
**지금 DB 칸이 아니다.** 원문 표현은 그대로 두고, 정렬용 값은 정렬에만 쓴다 — 화면에 날짜처럼 보이지 않는다.

| 원문 | 정밀도 | 정렬용 값 (안) | 표시 |
|---|---|---|---|
| 1997년에 가게 일을 시작했어요 | exact | 1997 | 1997년 |
| 1997년쯤 | approximate | 1997 | 1997년쯤 |
| 1980년대에 이사를 했어요 | range | 1980~1989 — 대표값 **미결** | 1980년대 |
| 환갑 때 | relative | 없음 (출생연도로 계산하지 않는다) | 환갑 때 |
| 언제였는지 기억나지 않아요 | unknown | 없음 | 때 모름 |

지시서 합성 목록으로 본 지금 상태:

| 별칭 | 작성 시각 | 사건 시점 | 작성순 (지금) | 연대기순 |
|---|---|---|---|---|
| r-a | 10-20 09:00 | 1997 (exact) | 4 | 1983 보다 뒤 — 확정 |
| r-b | 10-21 09:00 | 1983 (exact) | 3 | 1997 보다 앞 — 확정 |
| r-c | 10-22 09:00 | 1980년대 (range) | 2 | **미결** — 1980 으로 놓나, 기간 끝으로 놓나 |
| r-d | 10-22 10:00 | 모름 | 1 | **미결** — 맨 앞 · 맨 뒤 · 따로. 목록에서 빼지 않는다 |

## 4. 결정할 것

| 항목 | 후보 | 담당 |
|---|---|---|
| 한 회차에 사건이 여럿일 때 대표 시점 | 가장 이른 것 / 처음 말한 것 / 대원 님 추출이 고른 것 | 충 + 대원 + 승우 안 → 태헌 |
| 기간 (1980년대) 의 위치 | 시작 연도 / 따로 묶음 | 같음 |
| 시점 모름의 위치 | 맨 뒤 / 맨 앞 / 별도 묶음 | 같음 |
| 같은 시점끼리 순서 | 작성 시각 → `session_id` (흔들리지 않게) | 충 안 |
| 기본 방향 | 오래된 것부터 / 최근 것부터 | 승우 · 태헌 |
| 정렬하는 곳 | **서버 권장** — 화면은 받은 쪽만 보므로 100개 넘으면 일부만 정렬하게 된다 | 충 + 승우 |
| 더 보기 · 다음 쪽 | 지금 없음. 넣으면 정렬 기준과 함께 커서를 준다 | 충 + 승우 |
| 정정 · 제외 뒤 시점 | 최신 유효 원문에서 다시 뽑는다. 옛 시점을 재사용하지 않는다 | 대원 (추출) · 충 (언제 다시 뽑나) |
