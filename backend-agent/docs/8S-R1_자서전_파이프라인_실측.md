서비스 연결(단위 8S, PR #14)의 **비교 기준**이다. 같은 설정 · 같은 자료로 다시 재서 이 표와 맞대어 본다.
품질 승인 자료가 아니다 — 시간 · 토큰 · 비용 · 실패 위치만 적는다 (태헌 10-28: 기능 연결과 콘텐츠 품질 승인은 따로).

## 1. 자료와 도구

- 자료: 합성 seed **C · A · B** (13회차). n 개는 그 차례로 채운다 — 13개를 넘으면 같은 회차가 되풀이된다.
  39회차 = 말씀 162턴 · 입력 37,944자. 실제 어르신 자료는 쓰지 않았다.
- 도구: `python tools/memoir_pipeline_measure.py 39` — 서비스와 같은 `memoir.merge` → `memoir_pipeline.run`. DB · 서버 없음.
- 서버 경로 확인: 시험 서버(로컬 시험 DB `memoir_test`, 시험 계정)에서 `POST /api/memoirs` → `GET` 반복 → `done`.

## 3. 그 밖의 실행 (같은 날)

| 모델 · 설정 | 회차 | 결과 | 시간 | 멈춘 곳 |
|---|---|---|---|---|
| flash-lite · 기본 | 5 · 13 · 39 | 실패 ×3 | 13~17초 | 분석 — heard 사실 없음 · 8000 토큰 잘림 · partial/whole 겹침 |
| flash-lite · 분석 32768 | 5 · 13 · 39 | 실패 ×3 | 13~17초 | 분석 — source 허용값 · 사실에 안 든 턴 |
| Pro · 분석만 32768 | 5 | partial | 155.9초 | 장 ch-2 — 출력 6000 잘림 |
| Pro · 분석만 32768 | 13 · 39 | 실패 ×2 | 109 · 172초 | 목차 — 출력 6000 잘림 |
| Pro · 전 단계 32768 | 5 (seed C) | 실패 | 83.8초 | 분석 — 같은 턴이 partial 과 whole 에 함께 |
| Pro · 전 단계 32768 | 39 | **generated** | 368.9초 | — |
| Pro · 서버 작업 방식 | 5 (seed A · 말씀 8턴) | **done ×2** | 97 · 101초 | — |
| Pro · 전 단계 32768 | 39 | **generated** | 364.6초 | — (2절 기준 실행) |

- 실패는 모두 **분석 단계의 코드 검사**에서 났다. 분석 형식 · 허용값(`format`) · 호출(`call`) 오류는 이제 한 번 더 부른다
  (`memoir.RETRY_KINDS`, 태헌 10-28). 정정 · 제외 · 화자 · 출처(`reference`)와 시간 · 잘림은 그대로 멈춘다.
- 실패해도 그때까지 쓴 비용은 든다 — 39회차 분석 한 번 약 $0.36.
- 시간은 입력 크기를 따른다 (말씀 8턴 약 100초 · 162턴 약 365초). Cloudflare 100초 제한을 넘으므로 작업 방식
  (`POST /api/memoirs` → `GET /api/memoirs/{job_id}`)으로 연결했다.
