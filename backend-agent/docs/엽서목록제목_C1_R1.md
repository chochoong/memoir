## C1 — 필드 · 자료형 · 빈 값

`GET /api/sessions` (`?limit=` · `?has_postcard=1`) 의 회차마다:

| 칸 | 뜻 | 값 |
|---|---|---|
| `session_id` | 회차 | 그대로 |
| `title` | **회차 제목.** 엽서 제목으로 덮지 않는다 | 문자열 (빈 문자열 가능) |
| `has_postcard` | 엽서가 있나. 제목 유무와 따로 | `true` / `false` |
| `postcard_title` | **저장된 엽서 제목.** 상세 `/record` 의 `postcard.title` 과 같은 칸을 읽는다 | 문자열 또는 `null` |
| `created_at` | 회차 시각. 엽서를 다시 구워도 바뀌지 않는다 | ISO 시각 |
| 그 밖 | `user_id` · `photo_id` · `state` · `turn` · `max_turn` · `t2_seconds` · `closed_reason` · `closed_at` · `fragment_count` | 그대로 |

| 저장 상태 | `has_postcard` / `postcard_title` |
|---|---|
| 엽서 있음 · 제목 있음 | `true` / 저장 제목 |
| 엽서 있음 · 제목 `""` 또는 공백 | `true` / **저장값 그대로** (`""` · `"   "`) — 서버는 다듬지 않는다 |
| 엽서 있음 · 제목 NULL (006 전 엽서) | `true` / `null` |
| 엽서 없음 | `false` / `null` — **칸은 빠지지 않는다** |
| DB 를 못 읽음 | 목록 대신 **503** `{"detail": ...}` — 빈 목록으로 주지 않는다 |
| 정상 · 0개 | `{"sessions": []}` |

- 칸이 아예 없으면 `5a9fddd` 전 서버다. `null` 과 다르다 — 정상 빈 제목으로 보지 말고 버전 문제로 적는다.
- 서버는 제목을 만들지 않는다. 목록을 읽는 것으로 엽서를 굽지 않는다.
- DB 의 `postcard.title` 은 `TEXT` · NULL 허용 · 제약 없음 (006). 숫자 · 배열 같은 다른 자료형은 서버에서 나올 수 없다 — 화면의 모의 시험 몫이다.
