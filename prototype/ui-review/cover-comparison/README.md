# 표지 후보 비교

2026-11-09. 사용자 표지 참고 자료의 재질·색·얇은 양장 구조 방향을 확인하기 위한 독립 정적 비교 시안이다. 사용자가 **A/B/C의 3색을 표지에 순환 적용하는 방향**을 선택했다. 서비스 전체 테마 변경을 의미하지 않는다.

- 비교 페이지: `index.html`
- 후보 판: `cover-candidates-burgundy-navy-green.png` (1536×1024 PNG)
- A: 버건디 + 금빛 제목
- B: 네이비 + 아이보리 제목
- C: 딥그린 + 금빛 제목
- 제목과 부제는 예시: “나의 이야기” / “작은 기록”

세 권은 동일한 제목·작은 상징·구도·크기·얇은 양장 형태다. 무광 표면의 은은한 불규칙 결, 책등 홈, 단단한 보드와 좁은 페이지 단면을 비교한다. 페이지의 약148px 폭 미리보기는 같은 원본을 CSS로 잘라 보여 주며 별도 이미지 가공은 하지 않았다.

## 범위와 검수

최초 이미지 제작에서는 제품 파일·기존 표지를 수정하지 않았다. 이후 사용자 선택에 따라 `../library-view.css`의 책 표지에 버건디·네이비·딥그린 순환 방향과 얇은 양장 표현을 반영했다. 이 비교 페이지 자체는 실제 데이터에 연결되지 않은 정적 시안이다. 저장 데이터·API 설정은 수정하지 않았고 외부 게시·commit·push하지 않았다. 사용자 참고 도서 이미지는 이 폴더에 복제하지 않았다.

생성 결과를 시각적으로 확인했다. 한글 제목과 부제, 색상 구분, 절제된 작은 상징, 얇은 양장 구조가 보인다. 규칙적인 격자·세로줄이나 참고 도서의 로고·특유 문양·레터링은 보이지 않는다. 이미지는 디자인 방향 비교용으로, 실제 인쇄 재료·두께를 증명하는 사진이 아니다. 실제 제품 카드에 반영한 뒤의 최종 가독성 확인은 별도다.
