# develop 서버 연결 준비 계획

2026-11-09 · 기준 로컬 develop `7400e51c9b915d4de671b670e02857ab9e6d8cd5`

**Goal:** 확정된 UI를 유지하며 현재 develop API로 연결 가능한 프론트 코드를 준비하고, 서버 담당자가 다음 날 이어 할 계약·검증을 재현 가능하게 남긴다.

**Architecture:** 기존 순수 변환기·선택 정책 앞에 주입식 API 클라이언트와 자서전 생성 제어기를 둔다. 실제 인증·네트워크는 이 정적 시안에 자동 연결하지 않는다. 개발용 점검 스크립트로 실제 서버 소스와의 계약 일치를 오프라인 검증한다.

**Tech Stack:** 기존 vanilla JavaScript UMD/CommonJS, Node 내장 test runner. 새 의존성 없음.

**Spec:** 사용자의 “최대한 맞출거 맞춰두자. 내일 서버 담당자 오면 바로 할 수 있게.” 요청 및 [기존 호환성 전달서](COMPATIBILITY_HANDOFF.md).

## 작업 기준

- 변경은 `prototype/ui-review/` 내부. 원본 정적 화면·React·서버·브랜치 참조는 변경하지 않는다.
- 현재 PC 4메뉴·모바일 4메뉴·리더 비율·표지 3종·개인화 제목 등 확정 디자인을 보존한다.
- 실제 OAuth·API·음성·DB 연결, 배포·커밋·푸시는 이번 준비 작업에 포함하지 않는다.
- 프론트 계약은 조사한 develop 소스에 맞춘다. 미지원 문체·정상 종료·일시정지·영구 책 저장을 기존 API에 임의 대응시키지 않는다.
- 시안의 무상한 선택·문체 예시는 유지하되 실제 요청에는 서버 정책 검증을 반드시 적용한다. 선택한 자료를 숨겨서 늘리거나 줄이지 않는다.
- 서버 문서에 명시된 영구 저장과 생성 작업의 수명, UI 예시와 실제 문체 적용을 구별한다.

## 검토 초점

- 401 또는 화자 변경 후 늦게 도착한 응답이 이전 사람의 글을 다시 화면에 넣지 않게 한다.
- busy 작업을 현재 화자의 작업으로 단정하거나 다른 선택을 적용한 것처럼 표시하지 않는다.
- pipeline의 null 상한을 직접 선택 무제한으로 오인하지 않는다.
- 실패·취소·부분 결과·작업 만료를 읽을 수 있는 완성책으로 승격하지 않는다.
- 목록 100개가 전체라고 추정하거나 선택 순서를 서버의 결과 순서라고 약속하지 않는다.

## 구현 순서

- [x] 기존 시안 67개 파일 중간 ZIP 백업과 파일별 SHA256 매니페스트 생성.
- [x] `server-client.js/.test.cjs`: 주입된 fetch로 기존 경로·쿠키·JSON·오류·취소 계약을 구현. 실제 호출 없이 RED→GREEN 검증.
- [x] `memoir-controller.js/.test.cjs`: 메타·문체 검증, 작업 시작/조회/취소, busy와 만료, 화자 전환 및 늦은 응답 격리. 자동 polling 없음.
- [x] 예시 자료 나열을 서버 merge 입력의 회차 시작 시각 정렬과 일치시키고 해당 회귀 검증. 실제 모델의 장 순서는 응답 그대로 보존.
- [x] 실행 가능한 오프라인 점검 명령, 담당자용 요청·응답 예시·연결 순서·남은 계약 및 나비효과 기록.
- [x] 전체 시안 테스트·구문 검사·독립 계약 검토. 확인한 범위와 실제 연결의 미검증 범위를 별도 기록.

## 역할과 파일 소유

- API 클라이언트 담당: `server-client.js`, `server-client.test.cjs`.
- 작업 제어기 담당: `memoir-controller.js`, `memoir-controller.test.cjs`.
- root: 백업·시안 생성 정렬·점검 도구·인계 문서·통합 검증.
- 독립 검토: develop 서버 소스 계약을 읽기 전용으로 대조한다.

서버 엔드포인트를 새로 만드는 대신 기존 계약에 맞춘 준비를 택했다. 서버 계약 변경과 운영 프론트 채택은 내일 담당자가 결정할 항목으로 남긴다. 사용자의 기존 직접 실행 요청에 따라 이 계획을 같은 작업에서 실행한다.

## 완료 검증

클라이언트 37개·제어기 26개와 통합 4개를 포함하여 전체 175/175 통과, JS/CJS 31개 구문 통과, 기준 서버 소스 9개 일치를 확인했다. 독립 검토에서 확인한 401 전역 콜백 경합을 RED→GREEN으로 수정했고, 브라우저의 예시 자료 순서와 warn/error 0건도 확인했다. [검증 기록](SERVER_VERIFICATION.md) 참조. 실제 서버 호출·인증·음성·DB·배포는 실행하지 않았다.
