## 확인한 동작

- 클라이언트의 기존 API 경로·쿠키·JSON·204·422/401/409·요청 취소 처리와 원본 오류 보존.
- 현재 화자·회차 자격·서버 문체·선택 모드 검증, 정상 작업 시작/조회/취소·busy·만료·부분 결과의 읽기 제한.
- 실제 클라이언트와 제어기 조합으로 선택 UUID 전달→202→완성 응답→장/원문/출처 보존을 오프라인 주입 transport로 확인.
- pipeline의 직접 선택 상한 미확인과 미지원 문체는 요청 전 차단. 전체 제외 모드는 사용자 의도와 서버 메타에 따라 별도 전달.
- 화자 전환·reset·조회/취소 경합 뒤 오래된 결과 무시. 늦은 401·본문 읽기 중 AbortError·취소된 signal은 새 계정 상태를 지우지 않음. 현재 요청의 실제 401은 정상 전달.
- 독립 검토에서 발견한 인증 콜백 경합은 실패 재현 후 수정했습니다. 화자 지정 재요청의 200/409 구분과 전체 제외 모드의 엔진별 상한도 전달서에 반영했습니다.

## 브라우저 확인

새 인앱 브라우저에서 정적 시안을 열어 엽서 선택 1→3→2→문체→예시 초안 흐름을 실행했습니다. 선택 정보는 유지되고 본문은 원래 회차 시작일에 따라 3→2→1로 모였습니다. 4문체 예시와 기존 네 메뉴는 유지됐으며 console warn/error는 **0건**입니다. 실제 모델의 장 순서를 회차 순서로 약속한 검증이 아닙니다.

## 실제 환경 확인이 남은 범위

실제 OAuth·API·마이크/STT/TTS·DB 저장·운영 빌드/배포·실제 스마트폰은 이번에 실행하지 않았습니다. 시안의 `connect-src 'none'; media-src 'none'`도 유지했습니다. 생성 작업은 영구 책 저장과 다르며, 자세한 연결 순서·API 예시·서버 협의 항목은 [SERVER_TOMORROW.md](SERVER_TOMORROW.md)에 있습니다.

이번 작업 전 소스 67개 ZIP 백업과 SHA256 매니페스트를 만들었습니다. 백업과 전달 ZIP은 소스·디자인 보관용이며 브라우저 탭에 입력한 사용자 이야기를 저장하지 않습니다.
