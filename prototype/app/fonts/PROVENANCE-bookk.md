# 자서전 본문 글꼴 — 부크크 명조 Light

- 쓰는 곳: 자서전 읽기 화면(이북) 본문과 자서전 초안 본문. 「보기 설정 → 본문 글꼴」에서 기본 명조로 되돌릴 수 있다. 사이트 전체 글꼴은 바꾸지 않는다.
- 파일: `bookk-myungjo-light.woff2` (952,200바이트, SHA-256 앞 16자리 `dbdd74261770d945`)
- 받은 곳: 눈누(noonnu)가 배포하는 웹폰트 저장소 `projectnoonnu/noonfonts_2302` 의 `BookkMyungjo-Lt.woff2` 를 **원본 그대로** 사용. 잘라내거나(subset) 고치지 않았다.

- 담고 있는 글자: 현대 한글 11,172자 전부, 모두 12,263자.
- **확인 필요**: 글꼴 파일 안에 사용 허락 문구가 없다. 부크크가 공개 배포하는 무료 서체로 알려져 있으나, 정식 서비스에 쓰기 전에 부크크 공식 안내에서 웹 임베딩 · 상업적 사용 조건을 확인한다.
- 굵은 글씨(Bold) 파일은 크기 때문에 넣지 않았다. 굵게 표시할 곳은 브라우저가 굵게 그린다.
