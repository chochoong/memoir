# prototype — 시연용 HTML 화면

사진 한 장과 목소리로 이야기를 나누고, 끝나면 한 장의 엽서로 보여주는 화면입니다.
`backend-agent` 서버에 연결해서 돌아갑니다. 파일은 `index.html` 하나뿐입니다.

> `frontend-client`(리액트)가 나오기 전까지 시연에 쓰는 임시 화면입니다.
> 시연이 끝나면 리액트로 옮길 예정입니다.

## 실행 방법

`backend-agent` 폴더에서 PowerShell을 엽니다.

**처음 한 번만**

```
pip install -r requirements.txt
copy .env.example .env          ← 열어서 키를 채웁니다 (아래 표 참고)
mkdir web\assets
```

**매번**

```
copy ..\prototype\index.html web\index.html
.\run.ps1 -Dev
```

브라우저에서 `http://127.0.0.1:8010` 을 엽니다. 서버가 켜져 있는 동안 PowerShell 창은 닫지 마세요.

- `web` 폴더는 git이 무시합니다. **원본은 이 `prototype` 폴더에 있는 파일**이고,
  `web`에는 실행할 때 복사만 합니다. 이 파일을 고친 뒤에는 복사를 다시 해야 반영됩니다.
- 파이썬은 3.10 이상이어야 합니다.

## .env 에 필요한 값

| 항목 | 없으면 |
|---|---|
| `AZURE_SPEECH_KEY` | 말을 글자로 바꾸지 못합니다. **이게 없으면 대화가 진행되지 않습니다** |
| `GEMINI_API_KEY` | AI 질문 대신 고정 질문 3개만 나옵니다 |
| Postgres (`PG_*`) | 대화와 엽서는 정상입니다. 사진을 서버에 **저장**하는 것만 안 됩니다 |

**리허설할 때:** 회차는 10분에 10번까지만 열 수 있습니다. 여러 번 돌려 볼 때는
`.env` 에 `CREATE_MAX_PER_WINDOW=0` 을 넣고, **시연이 끝나면 지웁니다.**

`.env` 는 절대 커밋하지 마세요. API 키가 들어 있습니다.

## 화면 흐름

1. 사진 고르기 (선택)
2. **녹음 시작** → 마이크 허용
3. 캐릭터가 질문을 읽어 주고, 다 읽으면 "듣고 있어요"로 바뀝니다
4. 말을 마치고 조용히 있으면 **약 8초 뒤** 다음 질문이 나옵니다
   (3초 침묵 = 말이 끝남 + 5초 여유)
5. **녹음 정지 · 엽서 만들기** → 엽서 → **엽서 저장**(PNG)

### 지금 녹음 중인지 한눈에

| 상태 | 화면 |
|---|---|
| **녹음 중** | 붉은 점이 뛰는 「녹음 중이에요」 칩 · **이야기 영역을 감싸는 붉은 테** · 목소리 크기 막대 · 캐릭터 뒤 따뜻한 빛 |
| **읽어 주는 중** | 푸른 점 「읽어 드릴게요」 칩 · 테 없음 · 막대 없음 · 캐릭터가 한 걸음 물러남 |
| **정리 중** | 회색 점 「잘 들었어요」 칩 · 캐릭터가 쉼 |

붉은 테와 막대, 캐릭터 뒤 빛은 **실제 목소리 크기에 따라 진해집니다.**
말하는 동안에는 막대 아래 문구가 「잘 들리고 있어요」로 바뀌어, 마이크가
소리를 받고 있다는 것을 글자로도 알려 줍니다.

붉은 테는 **아래 버튼 자리 위에서 끊어집니다.** 화면 끝까지 내리면 테의 아랫변이
「녹음 정지」 버튼을 가로지르는 것처럼 보였습니다 (v0.9.1 에서 고침).

### 녹음 중 버튼

| 버튼 | 하는 일 |
|---|---|
| **녹음 정지 · 엽서 만들기** | 회차를 닫고 엽서를 만듭니다 (`POST /abort`) |
| (소리 없이 넘어가기) | 질문 소리가 안 나올 때**만** 나타납니다 |

**일시정지는 팀 논의로 뺐습니다**(2026-09-23). 코드는 남아 있고,
`CONFIG.ui.showPauseButton` 을 `true` 로 바꾸면 그대로 살아납니다.

> 서버에는 「일시정지」가 없습니다. 3초 동안 아무 소리도 안 올라오면 말이 끝난 것으로
> 보기 때문에, 멈춘 동안에는 아주 짧은 무음을 2초마다 올려 회차를 붙들어 두는 방식으로
> 만들었습니다. 마이크는 실제로 꺼 두므로 그 사이의 말은 녹음되지 않습니다.

**「다 말했어요」**(기다리지 않고 다음 질문으로)는 기본적으로 숨겨져 있습니다.
개발용 패널(⚙)에는 항상 있습니다. 말이 하나도 녹음되지 않은 상태에서 누르면
서버가 조용히 다시 듣기로 돌아가므로, 화면에 안내가 잠깐 뜹니다.

## 엽서 저장

완성 화면의 **엽서 저장**을 누르면 PNG 이미지 한 장으로 내려받습니다.
화면을 찍는 것이 아니라 1080px 폭으로 다시 그리기 때문에, 카카오톡으로 보내거나
인쇄해도 글자가 깨지지 않습니다. 사진이 있으면 위에 함께 들어갑니다.

파일 이름은 `memoir-postcard-20260923-1830.png` 처럼 영문으로 나갑니다.
한글 이름은 환경에 따라 통째로 버려지는 경우가 있어 기본을 영문으로 두었습니다
(`CONFIG.ui.filenameAscii`).

## 백엔드와 맞춘 것

API 이름과 경로는 `frontend-client/src/api.ts` 와 같습니다. 녹음 코드는 `recorder.ts`,
낭독 코드는 `speaker.ts` 를 일반 자바스크립트로 옮긴 것입니다.

| 백엔드 | 화면에서 쓰는 곳 |
|---|---|
| `POST /api/sessions` | 이야기 시작하기 |
| `GET /api/sessions/{id}` (0.3초마다) | 화면 전환. `snapshot.state` 가 유일한 기준 |
| `GET /question/audio` · `POST /tts-done` | 질문 낭독 → 듣기 시작 |
| `POST /speech/audio` (`audio/pcm;rate=16000`) | 목소리 올리기 (소리 나는 구간만) |
| `POST /done` · `POST /abort` | 다 말했어요 · 이야기 마치기 |
| `POST /api/photos` | 사진을 고르는 순간 올림 → 서버가 곧바로 §2 분석을 시작 |
| `POST /api/sessions` 의 `photo_id` | 그 사진의 단서로 **여는 말**을 지음 |

## 사진을 보고 먼저 물어보기 (연결됨)

기획서 §2 「사진 분석 에이전트」입니다. 백엔드가 **사진을 올리는 그 자리에서**
분석을 걸어 두고(`photo.analyze_later`), 회차를 열 때 그 단서로 **여는 말을 짓습니다.**

그래서 화면은 이렇게 돕니다.

1. 사진을 **고르는 순간** 서버로 보냅니다 (`POST /api/photos`)
   — 어르신이 사진을 보고 시작 단추를 누르기까지의 몇 초가 분석 시간이 됩니다
2. 시작을 누르면 `POST /api/sessions` 에 **`photo_id` 를 함께** 보냅니다
3. 서버가 단서를 찾으면 **첫 질문부터 사진 이야기**가 됩니다

| 상황 | 여는 말 |
|---|---|
| 사진 없음 | 「오늘은 어떤 이야기를 들려주시겠어요?」 |
| 사진 있음 · 분석됨 | §2 가 만든 **그 사진에 대한 질문** |
| 사진 있음 · 분석 실패·지연 | 「사진 잘 받았습니다. 이 사진은 어떤 사진인가요?」 |

업로드가 실패해도 회차는 평소대로 열리고, 사진은 화면과 엽서에 그대로 들어갑니다.
아직 올라가는 중에 시작을 누르면 최대 8초까지만 기다립니다 (`waitBeforeStartMs`).

> 사진 분석에는 Gemini 키가 필요합니다. 키가 없으면 서버 로그에
> 「GEMINI_API_KEY 없음 — 사진 분석을 건너뛴다」가 찍히고 위 표의 세 번째 줄로 갑니다.

## 설정 바꾸기

`index.html` 안 `<script>` 맨 위의 `CONFIG` 에 모여 있습니다.

| 값 | 기본 | 설명 |
|---|---|---|
| `photo.upload` | `true` | `false` 면 사진을 서버에 올리지 않고 화면 안에서만 씁니다 |
| `photo.uploadOnPick` | `true` | 사진을 고르는 순간 올립니다 (서버가 그 사이 분석합니다) |
| `photo.sendIdOnCreate` | `true` | 회차를 열 때 `photo_id` 를 함께 보냅니다 |
| `card.server` | `false` | 백엔드에 카드 작성 API(기획서 ④)가 생기면 `true` 로. 실패하면 임시 정리로 자동으로 내려갑니다 |
| `session.pace` | `normal` | `fast`(3초) · `normal`(5초) · `slow`(7초) — 다음 질문까지의 여유 |
| `apiBase` | `''` | 서버가 이 화면을 직접 낼 때는 비워 둡니다 |
| `ui.labels` | — | **버튼 이름은 전부 여기서 바꿉니다.** 코드 안을 뒤질 필요가 없습니다 |
| `ui.showPauseButton` | `false` | `true` 면 일시정지 / 이어서 말하기 버튼이 되살아납니다 |
| `ui.showDoneButton` | `false` | `true` 면 「다 말했어요」를 화면에 내보냅니다 |
| `ui.filenameAscii` | `true` | `false` 면 내려받는 파일 이름에 한글 제목을 씁니다 |

## 알아둘 것

- **엽서 글은 아직 AI가 쓰지 않습니다.** 군더더기("어", "음", "그니까")를 지우고 문장을 끊는
  규칙 기반 임시 정리입니다. 카드 작성 API가 생기면 `card.server` 로 바꿉니다.
- **사진 분석(기획서 ②)은 아직 대화에 연결되어 있지 않습니다.** 사진은 저장되고 엽서에
  들어가지만, 사진을 보고 질문이 바뀌지는 않습니다.
- **서버가 꺼져 있으면** "서버 없이 화면만 보기" 버튼이 뜹니다. 미리 넣어 둔 대화로
  화면 흐름을 끝까지 보여줍니다. 시연장 비상용입니다.
- **오른쪽 위 톱니(⚙)** 를 누르면 개발용 패널이 열립니다. 지금 상태, 기록, 그리고
  마이크 없이 글자로 발화를 보내 볼 수 있는 입력창이 있습니다. 시연 중에는 닫아 두세요.
