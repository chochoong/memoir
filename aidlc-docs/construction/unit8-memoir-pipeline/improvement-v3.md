## N-1 편집 메모 위치 — 작업 종류로 나눈다 (승인)
v2 실패는 지운 문장을 "편집 뒤" 위치로 찾게 한 계약 문제였다. v3 계약:

```json
{"action": "delete",  "before": ["ch-3/p0/s2"], "after": [], "change": "", "reason": ""}
{"action": "merge",   "before": ["ch-1/p0/s0", "ch-1/p0/s1"], "after": ["ch-1/p0/s0"], ...}
{"action": "merge",   "before": ["ch-1", "ch-2"], "after": ["ch-1"], ...}      // 장 합치기
{"action": "rewrite", "before": ["ch-1/p0/s0"], "after": ["ch-1/p0/s0", "ch-1/p0/s1"], ...}  // 나누기 포함
{"action": "add",     "before": [], "after": ["ch-2/p0/s0"], ...}
```
| action | before (장 초안 위치) | after (편집본 위치) |
|---|---|---|
| delete | 1개 이상 | 0개 — 지운 문장이 편집본에 없는 것은 정상 |
| merge | 2개 이상 | 정확히 1개 |
| rewrite | 1개 이상 | 1개 이상 |
| add | 0개 | 1개 이상 |

- 위치 형식은 그대로 `title` · `ch-K` · `ch-K/title` · `ch-K/pP/sS`. before 는 목차의 장 키 · 장 초안의 문단/문장, after 는 편집본의 장 키 · 문단/문장
- 개수가 틀리면 `format`, 초안 · 편집본에 없는 위치면 `reference` 실패 — **잘못된 위치는 계속 실패**
- 사실 · 출처 검사(R-1 · R-2 · 제외 턴 · from_chapters)는 그대로다. 위치 검사만 둘로 나눴다
- 회귀 테스트 T39 가 v2 실측(초안 ch-3 4문장 → 편집본 2문장, `ch-3/p0/s2` 를 편집 뒤 위치로 적은 메모)을 재현한다

## N-2 장 분할 원칙 (조건부 승인)
숫자 기준(최소 문단 수 등)과 하드코딩(사건 3개면 1장)은 두지 않았다. 지시문만 바꿨다.
- 목차 v3: "사건 하나마다 장 하나를 자동으로 만들지 않는다" · "시기 · 인물 · 장소가 다르다는 것만으로는 나눌 이유가 아니다" · **한 장 회상록을 먼저 검토** · 장을 따로 세우는 것은 다른 장으로 대신할 수 없는 독립 역할과 그 역할을 채울 원자료가 있을 때 · 나눴다면 `structure_reason` 에 사건 수가 아닌 편집적 이유 · 없는 공통 가치 · 인과 금지
- 편집 v3: 같은 기준으로 다시 보고, 사건 하나씩 담은 짧은 장이 나란히 있으면 합친다(`from_chapters`). 합치지 않았다면 이유를 `structure_notes` 에
- 검증 v3: `over_split` 정의를 같은 기준으로
- 코드: v2 의 경고("사건 하나마다 장 하나")를 그대로 두고, **검증 입력 `plan.checks` 로 넘긴다** — 판정은 검증 역할이 한다

## N-3 목차 메모의 본문 혼입 방지 (승인)
- 지시문: 목차 v3 은 purpose · grouping_reason · transition_in/out · direction · structure_reason 을 "내부 작성 메모" 로 짧은 방향 설명만 쓰게 하고, 장 집필 · 편집 v3 은 그 글을 본문에 옮기지 않으며 안내문("이 장에서는 …을 보여줍니다", "…으로 이어집니다", "마무리합니다") 대신 화자의 1인칭 해요체로 쓰게 했다. 도입 · 전환 · 마무리는 필요할 때만, 문장을 늘려 완결성을 만들지 않는다
- 코드:
  - `memo_leaks` — editorial 문장이 목차 메모와 글자(공백 · 부호 뺀) 그대로 같거나 메모 안에 통째로 있으면 **장 초안에서는 경고, 편집본에 남으면 `memo_leak` 실패**. supported 문장(원문을 옮긴 것)은 보지 않는다
  - `meta_sentences` — 안내문 말투 · 합니다체로 끝나는 문장은 경고(판정은 검증의 `style_mismatch`)
