# 단위 8P — 자유 산문형 집필 진단 실험 준비 (Seed C, 호출 전)

- 날짜: 2026-10-27
- 목적: v5 · v6 편집이 책다운 수필에 이르지 못한 원인이 글쓰기 계약(JSON 문장 객체 · 사실 원장 메모 · 초안)에 있는지 확인하는 **독립 진단**입니다. 다섯 단계 파이프라인을 대신하는 구현이 아닙니다.
- 실제 호출은 하지 않았습니다. 파이프라인 코드와 기본 모델 설정(Flash-Lite)도 바꾸지 않았습니다.

## 준비한 파일 (모두 새 파일)

| 파일 | 내용 |
|---|---|
| `backend-agent/eval/free_essay_C_prompt.md` | 시스템 지시 — 주제 · 쓰는 방식 · 사실 보존 규칙 · 정정 · 출력(제목 + 본문만) |
| `backend-agent/tools/memoir_free_essay.py` | 입력 생성, `--dry-run` / `--run`(호출 1회 · 재시도 0 · JSON 강제 없음), 기록 · 대조표 |
| `backend-agent/tests/test_memoir_free_essay.py` | 시험 5개 — 원문 그대로 전달, 원장 · 초안 · 예시 제목이 없음, dry-run은 호출 없음, 호출 1회 기록, 실패해도 재시도 없음, 글 모드 설정 |

## 모델에 주는 것
- 원문 턴 21개: 2, 3, 4, 10, 11, 12, 13, 14, 15, 17, 21, 25, 26, 27, 28, 29, 34, 35, 36, 38, 39
  - 각 턴마다 턴 번호, 회차, 인터뷰 질문, 어르신 답을 원문 글자 그대로 줍니다.
  - 범위는 목차 r2 장이 쓴 원문과 같고(장 집필 · v5 · v6 편집과 비교할 수 있게), 여기에 턴 28(부산 첫 방문 · 바다)을 더했습니다.
- 정정: 개업은 1985년 봄입니다. 86년은 쓰지 않습니다(턴 21 · 25).
- 보존 규칙: 전언, 기억하지 못함, 흐린 기억, 부정, 감정과 그 세기, 인물 관계. 인과와 장면을 지어내지 않습니다.
- 주제: 큰언니와 재봉틀

## 모델에 주지 않는 것
- 사실 원장 · 메모 · 요약(shared_state)
- 목차 · 문단 계획 · 핵심 사실 목록
- Pro 초안 · v5 · v6 편집본
- JSON 계약
- 「언니가 남긴 소리」 등 예상 정답 수필 (시험이 제목과 문장이 없는지 확인합니다)

## 뺀 턴
- 33: 남편의 별세 — 어르신이 "오늘은 그만할게요"로 멈춘 대목
- 1, 5~8, 9, 16, 18~20, 22~24, 30, 31, 32, 37: 다른 사람 · 다른 이야기
- 경계에 있는 턴 — 넣을지 태헌님이 정합니다:
  - 9: 오 남매 중 넷째, 위로 언니 둘. 큰언니와의 관계를 알려 줍니다.
  - 32: 아들이 말이 없다, 큰언니를 닮았다고 내가 말함. 큰언니와 직접 관련되고 화자의 생각(view)입니다.
  - 1: 대전에서 수선집을 오래 함

## 실행
- 설정: `gemini-3.1-pro-preview`, 온도 1.0, 출력 상한 32,768, 300초, 호출 1회, 재시도 0
- 응답은 JSON 모드가 아니라 글 그대로 받습니다.
- dry-run 결과:
  - 입력 약 1,684 토큰(지시문 1,189자 + 원문 2,146자)
  - 예상 비용: 출력 3,000이면 $0.039, 12,000이면 $0.147, 상한까지 다 쓰면 $0.397
  - 지난 Pro 호출들의 생각 토큰이 5~16k였으므로 **$0.05~0.20**으로 봅니다.
- 실행 명령 (`backend-agent`에서):

```bash
.venv/Scripts/python tools/memoir_free_essay.py --seed eval/memoir_seed_C.json --aliases c1,c2,c3,c4,c5 --run
```

- 기록: `eval/runs/<시각>-C5-b9f8-free-essay-31propreview/`
  - `00_input.json`: 지시 · 원문 · 설정
  - `01_essay.raw.txt`
  - `평가용_수필.md`: 본문만
  - `검수자용_대조표.md`: 수필 + 원문 턴 + 판정 칸
  - `run.json`: 커밋 · 시간 · 토큰 · finish

## 평가
- 평가자는 `평가용_수필.md`만 읽고 「언니가 남긴 소리」와 견줍니다. 그 예시는 모델에 보여 주지 않았습니다.
- 사실은 검수자가 대조표로 따로 판정합니다:
  - 원문에 없는 사실
  - 전언과 직접 기억의 구분
  - 불확실성
  - 부정 · 감정 · 인물 관계
  - 정정
  - 빠진 중요한 기억
- 사실에 문제가 있으면 문학적 완성도와 관계없이 실패입니다.
