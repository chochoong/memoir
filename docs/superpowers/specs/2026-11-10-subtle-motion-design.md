# 은은한 탄성 · 하단 아이콘 스냅

사용자는 동작 비교에서 전체의 은은한 탄성과 하단 메뉴의 아이콘 스냅을 선택했다. 실제 적용 여부를 확인한 이번 요청에 따라 검토용 본 UI(`prototype/ui-review`)에 적용한다.

- 버튼은 즉시 약 2.5% 눌리고 짧게 복원한다. 화면과 네이티브 대화상자는 짧고 작은 등장 전환을 사용한다.
- 모바일 하단 메뉴는 선택 위치에서 즉시 색이 켜진다. 배경은 이동하지 않으며 글자는 고정하고 SVG 아이콘만 약 165ms 눌림·복원을 사용한다.
- 페이지 방식 독서는 기존 페이지 계산·보기 설정을 사용하면서 터치 가로 이동이 페이지를 직접 따라가도록 한다. 경계나 취소에서는 복귀하며 세로 스크롤과 글 선택을 보존한다.
- 시스템의 움직임 줄이기를 적용한다. 독서는 독서 설정의 움직임 줄이기도 적용한다. 동작을 위해 상태 변경이나 초점 이동을 지연하지 않는다.
- 승인된 흰 바탕·버건디 로즈, 기존 글꼴·크기·터치 영역·정보 구조를 기준으로 한다. API·인증·음성 수집·서버 코드 변경은 없다.

검토한 방식은 배경 이동(이전 시안), 제자리 스위치 스냅, 아이콘 스냅이다. 사용자는 아이콘 스냅이 더 자연스럽다고 선택했다. 일반 버튼의 약 210ms 복원과 180~220ms 등장 전환은 구현자가 정한 보수적인 세부 값이다.
