# 흰 바탕·버건디 로즈 테마

사용자는 2026-11-10 대화에서 마지막 흰 바탕 시안을 보고 “이버전으로 하자”로 적용을 승인했다. 기존 누런 기운을 줄이면서 심플하고 고급스러운 인상을 유지하고, 어르신이 현재 메뉴와 주요 조작을 알아볼 수 있게 한다.

- 전체 배경·헤더·카드: `#FFFFFF`.
- 제목·본문: `#292628`, 보조문구: `#696568`.
- 주요 버튼·선택 상태: 버건디 로즈 `#8A465E`, 옅은 선택 바탕 `#F7EAF0`.
- 일반 아이콘·보조 조작은 중성색. 현재 PC/모바일 메뉴는 색·옅은 바탕·밑줄을 함께 사용한다.
- 입력 경계와 키보드 초점을 유지한다. 선택 체크·오류·녹음 상태의 의미를 보존한다.
- 레이아웃·서체·치수·문구·탭 데이터·기능을 바꾸지 않는다. 삽화·3색 표지·책장 재질·독서 화면과 저장된 독서 설정을 유지한다.

## 검토한 방향

기존 따뜻한 색상의 노란 기운 감소안, 모브 플럼/버건디 로즈 비교, A/B/C 강조 비율 비교를 거쳐 흰 바탕과 로즈 포인트를 조합했다. 최종안은 C처럼 제목·일반 아이콘을 무채색으로 두고 B처럼 주요 버튼과 현재 메뉴를 강조한다. 비율 수치는 방향 비교용 목표였으며 실제 픽셀 면적이나 사용자 조사 결과가 아니다.

## 구현 선택

`prototype/ui-review/white-rose-theme.css`를 마지막에 로드하는 색상 전용 레이어로 추가한다. `body:not(.ebook-mode)`에 한정하여 기존 독서 테마 변수가 바뀌지 않도록 한다. 이전 제목 영역의 `#99546D` 선택보다 이번 전역 선택이 우선한다.

현재 검토 브랜치에서 진행하고 커밋·푸시·배포는 하지 않는다. 새 동작이 없는 가역적 색상 변경이므로 구현을 복제하는 테스트는 추가하지 않고 기존 오프라인 검사와 실제 브라우저의 주요 화면·작은 화면·선택·초점·독서 예외를 확인한다.
